# AdventCalendar

AdventCalendar is a Minecraft plugin designed for Spigot/Paper servers, providing an interactive Advent calendar GUI for players. It features a 24-day calendar accessible via a single chest inventory, with each day offering unique rewards. The plugin supports both item rewards and server commands, making it highly customizable. It includes a lockout system to ensure players can only access days on or after December 21st, 2026, and provides admin permissions for testing purposes.

## Install

1. Download the plugin JAR file from the releases page.
2. Place the JAR file in the `plugins` folder of your Spigot/Paper server.
3. Restart or reload your server to load the plugin.
4. Edit the `config.yml` file in the plugin's folder to customize rewards for each day.

## Use

1. Players can open the calendar by typing `/calendar` in the chat.
2. Each day's item in the GUI will show the day number and a message to click to claim the reward.
3. If a day is not yet available, players will receive a message indicating when they can open it.
4. Once a reward is claimed, the item will turn into coal, and players will receive a message indicating the reward has been claimed or is no longer available.
